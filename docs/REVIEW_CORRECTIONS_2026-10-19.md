# 2026 ഒക്ടോബർ 19-ലെ തിരുത്തലുകൾ

## മലയാളം

മൂലശേഖരവും മുൻ സംഭാവനകളും Git ചരിത്രത്തിൽ നിലനിൽക്കുന്നു. ഈ തിരുത്തലുകൾ ചേർത്ത ഗവേഷണകരട് പ്രസിദ്ധീകരിക്കാൻ ഉടമ അനുമതി നൽകിയിട്ടുണ്ട്. ആ അനുമതി ഭാഷാവിദഗ്ധന്റെയോ ചരിത്രവിദഗ്ധന്റെയോ അംഗീകാരമല്ല. മനുഷ്യപരിശോധനയുടെ നില `pending` ആയി തുടരും.

- രണ്ടാം ശിലാശാസനത്തിന് 252 BCE എന്ന് Hultzsch-നെ അടിസ്ഥാനമാക്കി നൽകിയ തീയതി പിൻവലിച്ചു. പരിശോധിച്ച ഭാഗം ആ തീയതി സ്ഥാപിക്കുന്നില്ല.
- Edakkal-നെക്കുറിച്ചുള്ള Fawcett സന്ദർശനവർഷത്തിന് 1894, 1895, ഏകദേശം 1896 എന്നീ വ്യത്യസ്ത റിപ്പോർട്ടുകളുണ്ട്. അവ രേഖപ്പെടുത്തി; 1894 എന്ന ഒറ്റവർഷത്തിലെ കണ്ണി നീക്കി. 1894–1896 പരിധി എല്ലാ വർഷവും സന്ദർശനം നടന്നുവെന്ന് പറയുന്നില്ല.
- S009-ന്റെ ഉപസംഹാരത്തിന്റെ പേജ് 635 ആയി തിരുത്തി. 1956-ലെ നിയമത്തിന്റെ ഔദ്യോഗിക India Code സംയോജിത പാഠത്തിലെ നിർദ്ദിഷ്ട വകുപ്പുകൾ പരിശോധിച്ചു. മൂല ഗസറ്റ് ചിത്രങ്ങളും പിന്നീടുള്ള അതിർത്തിമാറ്റങ്ങളും ഇനിയും പരിശോധിക്കാനുണ്ട്.
- Muziris-നെ ഗ്രന്ഥനാമമാക്കിയ പരിഭാഷയും പ്രാചീന അടിസ്ഥാനശിലയെക്കുറിച്ചുള്ള പഠനത്തിന്റെ തലക്കെട്ടും ഉദ്ധരണികളുടെ എണ്ണത്തെക്കുറിച്ചുള്ള അധിക അവകാശവാദവും തിരുത്തി.
- ഇംഗ്ലീഷ് മാറിയാൽ പഴയ മലയാളത്തിന് പുതിയ hash നൽകി നിലവിലുള്ള പരിഭാഷയായി കണക്കാക്കുന്നത് തടഞ്ഞു. രേഖപ്പെടുത്തിയ മനുഷ്യപരിശോധനാ തീരുമാനങ്ങൾ വീണ്ടും ഇറക്കുമതി ചെയ്യുമ്പോൾ ഇല്ലാതാക്കില്ല.
- തെറ്റായ ഡാറ്റ, പരിഭാഷയിലെ format fields, നിരസിച്ച പരിഭാഷകൾ, ഭൂമിശാസ്ത്ര ഫയലുകളുടെ checksum എന്നിവയ്ക്കുള്ള പരിശോധനകൾ ശക്തമാക്കി. Manifest സ്വയം ഒഴികെ എല്ലാ tracked ഫയലുകളും ഉൾക്കൊള്ളുന്നു.

ഇന്റർനെറ്റിലെ എല്ലാ തെളിവുകളും പരിശോധിച്ചെന്നോ ചരിത്രം പൂർത്തിയായെന്നോ ഈ പതിപ്പ് അവകാശപ്പെടുന്നില്ല. [തുടർപരിശോധനയുടെ രേഖ](../notes/evidence-review/FOLLOWUP-2026-10-19.md), [ബാക്കിയുള്ള ചോദ്യങ്ങൾ](../notes/evidence-review/UNRESOLVED.md), [നിലവിലെ കവറേജ്](../coverage/README.md) എന്നിവ കാണുക. മനുഷ്യ ഭാഷാപരിശോധനയും സ്വതന്ത്ര ചരിത്രവിദഗ്ധപരിശോധനയും പൂർത്തിയായിട്ടില്ല. ഈ മലയാളം AI സഹായത്തോടെ തയ്യാറാക്കിയ കരടാണ്.
