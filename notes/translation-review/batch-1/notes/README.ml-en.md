# പ്രവർത്തന ഗവേഷണക്കുറിപ്പുകൾ

> പരിഭാഷാ കരട്. AI സഹായത്തോടെ തയ്യാറാക്കിയത്. മലയാള ഭാഷാപരിശോധനയും വിഷയവിദഗ്ധപരിശോധനയും ബാക്കിയുണ്ട്. മൂലപാഠം: `notes/README.md` @ `570f665`.

കൈകൊണ്ട് എഴുതിയ കുറിപ്പുകൾ തീയതി, സംഭാവകന്റെ തിരിച്ചറിയൽ (identifier), സ്രോതസ്സ് ID-കൾ, പരിശോധിച്ച ഭാഗങ്ങൾ, തുറന്ന ചോദ്യങ്ങൾ എന്നിവ സഹിതം ഇവിടെ സൂക്ഷിക്കുക. ഈ ഫയലുകൾ builder നിർമ്മിക്കുകയോ മാറ്റിയെഴുതുകയോ ചെയ്യുന്നില്ല. ഒരു അവകാശവാദത്തിന്റെ പിന്തുണ, തീയതി, പരിധി, പരിമിതികൾ എന്നിവ വ്യക്തമായശേഷം മാത്രം അതിനെ അടിസ്ഥാന ഡാറ്റയിലേക്ക് ഉയർത്തുക.

കുറിപ്പുകൾ എന്ന് പേരുള്ളതുകൊണ്ടുമാത്രം സംരക്ഷിത പൂർണപാഠങ്ങളോ സൂക്ഷ്മമായ വ്യക്തിവിവരങ്ങളോ ഈ ഫോൾഡറിൽ വയ്ക്കരുത്. പൊതു Git ചരിത്രം മായ്ച്ച വിവരങ്ങളും സൂക്ഷിച്ചേക്കാം.
